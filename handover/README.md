# Handover files

This folder is the portable context layer for the new Antigravity agent.

- `00_START_HERE.md` — mandatory entry point and current task.
- `01_PROJECT_CONTEXT_MASTER.md` — research, method, dataset, results, caveats, reviewer feedback, and roadmap.
- `02_AGENT_RULES.md` — persistent execution and evidence-preservation rules.
- `03_PHASE_STATUS.md` — completed phases and exact stop point.
- `04_NEXT_AGENT_PROMPT.md` — prompt to paste into the new Antigravity agent.
- `OUTPUT_REGISTER.csv` — sequential inventory of key source outputs, reports, and figures.

This is project memory/instructions, not a literal MCP server. Keep these files updated whenever a phase is approved and completed.
